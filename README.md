## 简介 / Introduction

一款专为内容创作者打造的 Android 提词器工具。悬浮窗可在任意相机/录制应用之上展示讲稿，内置离线语音识别实时跟踪你的语速自动滚动，无需联网、无广告、无隐私泄露。

An Android teleprompter built for content creators. The floating window overlays your script on any camera/recording app, with built-in offline speech recognition that auto-scrolls to match your pace — no network, no ads, no privacy leaks.

### 核心特性 / Features

- **悬浮提词** · Floating window over any recording app
- **语音自动滚动** · Voice-driven auto-scroll tracks your speech word-by-word
- **逐字高亮** · Word-level highlight + read-through strikethrough
- **完全离线** · 100% offline speech recognition (Vosk)
- **中英双语** · Bilingual UI (中文 / English)
- **边录边提词** · Works while you record video

## 下载 / Download

直接下载仓库中的 `ArtisanDev-Teleprompter-v1.0.apk` 即可安装。

Download `ArtisanDev-Teleprompter-v1.0.apk` from this repository to install.

## 安装 / Install

1. 下载上方 apk 文件 / Download the apk above
2. 在手机设置中允许"安装未知来源应用" / Enable "Install unknown apps" in Android settings
3. 点击 apk 完成安装 / Tap the apk to install
4. 启动后授予悬浮窗与麦克风权限 / Grant overlay + microphone permissions on launch

## 系统要求 / Requirements

- Android 8.0 (API 26) 及以上 / Android 8.0+ (API 26+)
- 麦克风权限 / Microphone permission
- 悬浮窗权限 / Overlay permission
